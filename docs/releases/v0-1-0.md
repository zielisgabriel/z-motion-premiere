# Z Motion 0.1.0: Toolkit prototype

Initial toolkit prototype with easing curves, entrance/exit recipes, static transforms and local presets.

This is an archived prototype. Its broader interface was superseded by the user-approved curve-only first release.

## Install

Close Premiere, download z-motion-0.1.0-setup.exe and run it. Alternatively, extract z-motion-0.1.0-windows.zip completely and run install-z-motion.cmd. Premiere Pro 26.x with CEP 12 is required. No Node.js or separate font installation is required on the editing machine.

This release is marked as a prerelease because it is the archived toolkit prototype.

## Validation and known limits

Historical checkpoint: 27 automated tests, five browser tests, isolated installer lifecycle and EXE installation passed. Native Premiere edits were not verified at that checkpoint.

The public Adobe API does not expose highlighted Effect Controls keyframe selection. The current curve-only workflow uses the existing pair around the playhead. Native writes are not atomic; restore the original pair if a failed attempt left intermediate keys.
