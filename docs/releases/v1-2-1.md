## Choose what gets the curve and the blur

Z Motion 1.2.1 lets you leave properties and Transform effects out, for example a Twixtor speed curve that shares the playhead with Scale and Opacity.

- **Curve properties:** the button above **Apply animation** previews the checked properties, such as "Animates Scale, Opacity" with a 2/3 count. Click it to open a dialog with one checkbox per property, showing its start and end values, plus **All**, **None** and **Done**. Esc or a click outside also closes it.
- Every property is checked when a new keyframe pair loads. Reapplying to the same pair keeps your choice. Only checked properties are validated and written, so a property you left out no longer blocks Apply.
- **Transform effects for motion blur:** when the selected clip has two or more Transform effects, the same picker appears above the shutter angle. Each Transform shows its current setting, "composition" or an angle. **Apply blur to clip** writes the angle to every checked Transform independently and names any that Premiere rejects. The heading reads "Current: mixed" when the checked effects differ. With a single Transform, no picker is shown.
- Premiere still does not let panels read which keyframes are selected in Effect Controls, so the panel offers every property keyed around the playhead and you uncheck the rest.

## Install

Save your project, close Premiere Pro and run **z-motion-1.2.1-setup.exe**. It upgrades an existing installation. Alternatively, extract **z-motion-1.2.1-windows.zip** completely and run `install-z-motion.cmd`.

Requires Windows and Adobe Premiere Pro 2026 with CEP 12. This unsigned build uses Adobe's per-user developer setting, explained by setup. Node.js and npm are not needed on the editing machine.
