# Z Motion 1.0.0: Curve-only editor

Replaced the broad toolkit with an easing graph, a sample-based motion preview and one Apply Animation action. Finds the existing keyframe pair around the playhead and inserts intermediate frame keys while preserving endpoint values and times.

## Install

Close Premiere, download z-motion-1.0.0-setup.exe and run it. Alternatively, extract z-motion-1.0.0-windows.zip completely and run install-z-motion.cmd. Premiere Pro 26.x with CEP 12 is required. No Node.js or separate font installation is required on the editing machine.

## Validation and known limits

Historical checkpoint: 24 automated tests and seven browser tests passed. The user subsequently reported a native Transform / Position key creation failure. Use 1.0.2 for the latest fixes.

The public Adobe API does not expose highlighted Effect Controls keyframe selection. The current curve-only workflow uses the existing pair around the playhead. Native writes are not atomic; restore the original pair if a failed attempt left intermediate keys.
