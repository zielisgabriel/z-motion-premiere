## Motion blur on the selected clip

Z Motion 1.1.2 adds motion blur controls for an existing Transform effect. Apply the setting to the entire selected clip without selecting keyframes or positioning the playhead between them.

- Set a shutter angle from 0° to 360°, with Off, 90°, 180° and 360° shortcuts.
- Use **Apply blur to clip** independently of **Apply animation**. Movement keyframes stay unchanged.
- See the selected clip name and reload the selection with **Refresh clip**.
- Recognize both legacy and current Premiere Transform effects, including `AE.ADBE Geometry2`, which caused disabled controls in the local 1.1.1 build.
- Choose the intended Transform instance when a clip has multiple effects. Existing animated shutter controls are preserved by refusing to overwrite them.
- Verify shutter values after writing and attempt to restore previous settings if a write fails.

## Install

Save your project, close Premiere Pro and run **z-motion-1.1.2-setup.exe**. Alternatively, extract **z-motion-1.1.2-windows.zip** completely and run `install-z-motion.cmd`.

Requires Windows and Adobe Premiere Pro 2026 with CEP 12. This unsigned build uses Adobe's per-user developer setting, explained by setup. Node.js and npm are not needed on the editing machine.

Select a clip with Transform, open Z Motion and use **Refresh clip → Apply blur to clip**. Visible blur comes from movement within Transform's Position, Scale or Rotation. Native Motion animation and movement photographed in source footage are not converted.
