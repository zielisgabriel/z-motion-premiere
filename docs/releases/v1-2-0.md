## One click curves every animated property

Z Motion 1.2.0 removes the property chooser and the motion preview, adds a one-click Transform button and a dark theme, and fixes clicks the panel used to ignore.

- **Apply animation** applies the curve to every property with a keyframe pair around the playhead (Position, Scale, Opacity and others). Premiere does not let panels read which keyframes are selected, so the line above the button lists what will change.
- A curve that one property cannot take, such as Opacity overshooting 0–100, keeps Apply disabled and names that property. Properties are applied independently; a failure names the property and those already updated.
- Curves now apply to the **Transform** effect. Premiere 26.5.1 returns `null` when linear interpolation is set on Transform keys, which used to abort a curve whose frame values had already been written and verified.
- The motion preview was removed.

## Add Transform to clip

- **+ Add Transform to clip** in the Motion blur section adds the Transform effect to every selected video clip, even one that already has it, and selects it for motion blur.
- It uses Premiere's undocumented QE DOM, the only scripting route that adds effects. Effect names are recognized in English, Portuguese, French, German and Italian; otherwise the panel asks you to use the Effects panel. Success is confirmed by checking that each clip gained exactly one Transform.

## Dark theme

The button at the right of the header switches between the default light theme and a dark theme built from the DESIGN.md palette: Pitch Black canvas, Vanilla type, Carmine accents and a Rule Charcoal graph. The panel remembers the choice.

## Fixes

- A click on **Apply animation**, **Apply blur to clip** or **Add Transform** that brought focus from Premiere was ignored: the selection reload it triggered disabled the button before the click arrived. Reloads are now silent and writes wait for them.
- The reason Apply is unavailable, or the latest result, sits directly above the button, so small panels always show it.
- Motion blur results and errors appear inside the Motion blur section.
- The 280×400 minimum panel no longer scrolls; short panels use a compact layout without larger type.
- Consistent headings, a red status dot when connected, the active preset keeps its colour on hover, and long clip names are shortened with the full name in a tooltip.

## Install

Save your project, close Premiere Pro and run **z-motion-1.2.0-setup.exe**. It upgrades an existing installation. Alternatively, extract **z-motion-1.2.0-windows.zip** completely and run `install-z-motion.cmd`.

Requires Windows and Adobe Premiere Pro 2026 with CEP 12. This unsigned build uses Adobe's per-user developer setting, explained by setup. Node.js and npm are not needed on the editing machine.
