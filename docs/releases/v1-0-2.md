# Z Motion 1.0.2: Scale readback precision

Accepts bounded storage rounding for generated scalar keyframes without loosening original endpoint, neighboring key, curve-plan or 2D Position checks. Readback errors include requested and stored values. Larger mismatches, clamping and no-op writes still fail.

## Install

Close Premiere, download z-motion-1.0.2-setup.exe and run it. Alternatively, extract z-motion-1.0.2-windows.zip completely and run install-z-motion.cmd. Premiere Pro 26.x with CEP 12 is required. No Node.js or separate font installation is required on the editing machine.

## Validation and known limits

38 automated tests, seven browser tests, installer lifecycle checks and isolated EXE installation passed at the product checkpoint. Position is user-confirmed in 1.0.1. Native Scale application and playback in 1.0.2 remain pending; fixture success does not certify Premiere rendering.

The public Adobe API does not expose highlighted Effect Controls keyframe selection. The current curve-only workflow uses the existing pair around the playhead. Native writes are not atomic; restore the original pair if a failed attempt left intermediate keys.
