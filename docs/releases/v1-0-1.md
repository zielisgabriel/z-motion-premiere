# Z Motion 1.0.1: Native Position keyframe compatibility

Corrected premature rejection of native key creation and mutation time arguments. Creation is confirmed with getKeys and generated values are read back. Preserves original endpoint and neighboring key values and times.

## Install

Close Premiere, download z-motion-1.0.1-setup.exe and run it. Alternatively, extract z-motion-1.0.1-windows.zip completely and run install-z-motion.cmd. Premiere Pro 26.x with CEP 12 is required. No Node.js or separate font installation is required on the editing machine.

## Validation and known limits

Historical checkpoint: 32 automated tests, seven browser tests and installer checks passed. The user confirmed Position works in this version, then reported a Scale readback error. Scale precision handling is included in 1.0.2.

The public Adobe API does not expose highlighted Effect Controls keyframe selection. The current curve-only workflow uses the existing pair around the playhead. Native writes are not atomic; restore the original pair if a failed attempt left intermediate keys.
